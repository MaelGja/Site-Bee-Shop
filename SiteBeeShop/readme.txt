📖 КОРОТКО О САЙТЕ
--------------------------------------------------------------------------------

«Пчеловод» — интернет-магазин товаров для пчеловодства с полноценной
админ-панелью. Сайт позволяет клиентам выбирать товары, оформлять заказы
с доставкой, а администратору — управлять каталогом и обрабатывать заказы.

🚀 УСТАНОВКА И ЗАПУСК
--------------------------------------------------------------------------------

ТРЕБОВАНИЯ:
  • PHP 8.0 или выше
  • Visual Studio Code (рекомендуется)
  • Расширение "PHP Server" для VS Code (или встроенный сервер PHP)

УСТАНОВКА:

  1. Скачайте все файлы проекта в одну папку, например:
        C:\projects\bee-shop\

  2. Убедитесь, что в папке проекта есть:
        ├── index.php              ← главная страница
        ├── admin.php              ← админ-панель заказов
        ├── admin-products.php     ← управление каталогом
        ├── products.csv           ← каталог товаров
        ├── readme.txt             ← этот файл
        └── assets/
             ├── style.css
             └── main.js

  3. Папки data/ и uploads/ создадутся автоматически при первом запуске.
     (если не создались — создайте вручную)

ЗАПУСК В VS CODE:

  Вариант А — через терминал VS Code:
     • Откройте папку проекта: File → Open Folder
     • Откройте терминал: Terminal → New Terminal
     • Введите команду:
           php -S localhost:8000
     • Откройте в браузере: http://localhost:8000

  Вариант Б — через расширение "PHP Server":
     • Установите расширение "PHP Server" (brapifra.phpserver)
     • Кликните правой кнопкой по index.php
     • Выберите "PHP Server: Serve project"
     • Браузер откроется автоматически

  Вариант В — через XAMPP/OpenServer/MAMP:
     • Скопируйте папку проекта в htdocs (или www)
     • Запустите Apache
     • Откройте: http://localhost/bee-shop/

👤 РЕГИСТРАЦИЯ КЛИЕНТА
--------------------------------------------------------------------------------

  1. Нажмите «Войти» в шапке сайта
  2. Переключитесь на вкладку «Регистрация»
  3. Заполните: имя, email, пароль (минимум 6 символов), повтор пароля
  4. Нажмите «Зарегистрироваться»

  После регистрации вы автоматически авторизуетесь и можете:
    – добавлять товары в корзину
    – оформлять заказы
    – видеть свой личный кабинет


--------------------------------------------------------------------------------
🛒 КАК СДЕЛАТЬ ЗАКАЗ (для тестирования)
--------------------------------------------------------------------------------

  1. Войдите как клиент (или зарегистрируйтесь)
  2. Пролистайте каталог → нажмите «В корзину» на нужных товарах
  3. Нажмите «🛒 Корзина» в шапке
  4. В модальном окне:
        – проверьте количество товаров (кнопки + / −)
        – выберите способ доставки
        – введите ФИО получателя (обязательно)
        – введите телефон (обязательно)
        – введите адрес (для доставки, не для самовывоза)
  5. Нажмите «Оформить заказ»


--------------------------------------------------------------------------------
📋 КАК ОБРАБОТАТЬ ЗАКАЗ (для администратора)
--------------------------------------------------------------------------------

  1. Войдите как admin@bee-shop.ru / admin123
  2. В шапке нажмите «📋 Заказы»
  3. На странице заказов:
        – сверху статистика: всего / новых / выручка
        – фильтры по статусу
        – список заказов с составом, адресом, ФИО получателя, телефоном
  4. Для изменения статуса:
        – выберите новый статус в выпадающем списке
        – нажмите «Сохранить»


--------------------------------------------------------------------------------
📦 КАК УПРАВЛЯТЬ КАТАЛОГОМ (для администратора)
--------------------------------------------------------------------------------

  1. Войдите как администратор
  2. Нажмите «📦 Каталог» в шапке

ДОБАВЛЕНИЕ ТОВАРА:
  • Нажмите «➕ Добавить товар»
  • Заполните:
      – Emoji (если не будет картинки) — например, 🍯
      – Название (обязательно)
      – Описание
      – Цена в рублях (обязательно, больше 0)
      – Старая цена (если больше текущей — появится скидка «−N%»)
      – Категория (Мёд, Ульи, Инвентарь…)
      – Изображение (jpg/png/gif/webp, до 5 МБ)
      – Галочка «🔥 Участвует в акции»
  • Нажмите «💾 Сохранить»

РЕДАКТИРОВАНИЕ:
  • Нажмите ✏️ напротив товара → измените поля → сохраните

УДАЛЕНИЕ:
  • Нажмите 🗑️ → подтвердите

ПОДСКАЗКИ:
  • Если загружена картинка — она заменит emoji на карточке товара
  • Скидка показывается, только если «старая цена» больше «текущей»
  • Бейдж «Акция» появляется при отмеченной галочке

📄 ФОРМАТ products.csv
--------------------------------------------------------------------------------

  Колонки (обязательно в этом порядке):

    id          Уникальный номер товара (1, 2, 3…)
    icon        Emoji-иконка (если нет картинки)
    image       Путь к картинке, например uploads/p_123.jpg
    name        Название товара
    description Описание
    price       Текущая цена в рублях
    old_price   Старая цена для скидки (0 = без скидки)
    category    Категория
    is_promo    1 = акция, 0 = обычный товар

  ПРИМЕЧАНИЕ:
    • Файл должен быть в кодировке UTF-8 (без BOM или с BOM — оба варианта
      поддерживаются)
    • Если открываете в Excel — сохраняйте как «CSV UTF-8», иначе
      русские буквы и emoji сломаются

⚠️  ВАЖНО ДЛЯ ПРОДАКШЕНА
--------------------------------------------------------------------------------

  Перед публикацией на реальном сервере:

  ✓ Смените пароль администратора в index.php
      (константа ADMIN_PASSWORD)

  ✓ Закройте папку data/ от публичного доступа:
      – создайте файл data/.htaccess с содержимым:
              Order deny,allow
              Deny from all
      – для nginx настройте location-блок с deny

  ✓ Настройте HTTPS

  ✓ Сделайте резервную копию файлов users.json и orders.json

  ✓ Подключите реальную отправку email/уведомлений
